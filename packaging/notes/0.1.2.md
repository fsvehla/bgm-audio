## What's new

- **Renamed to Ambience** (Dock, menu bar, window). Your playback positions and settings carry over.
- **Automatic updates** with [Sparkle](https://sparkle-project.org): Ambience checks for new versions daily, or use **Ambience → Check for Updates…**
- App menu: Hide (⌘H), Hide Others (⌥⌘H), Show All

## Install

Unzip and move `Ambience.app` to Applications. If you have `bgm-audio.app` from an earlier release, delete it; this is the same app under its new name. Signed with Developer ID and notarized; requires macOS 14.2 or later.
